# YouTube Chat

React + Vite + Tailwind frontend for the YouTube RAG API.

## Run locally

1. Start the backend at `http://localhost:8000`.
2. In this directory, install packages and start Vite:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`). Set `VITE_API_URL` in a `.env` file in this directory to use a different backend base URL. It defaults to `http://localhost:8000`.

Production build: `npm run build`; preview it with `npm run preview`.
